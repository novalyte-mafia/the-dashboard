## Sending hygiene

- One personalization line minimum; if you can't write a true one, the target doesn't belong in Tier 1.
- Never attach a deck to the first cold email; the portal replaces it.
- Log every send in OUTREACH-TRACKER.csv the same day.
- Batch ≤10/day so replies get fast, thoughtful responses.
