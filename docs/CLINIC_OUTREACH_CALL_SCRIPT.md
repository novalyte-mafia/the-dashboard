# Novalyte Clinic Outreach — Founder Call Script (Live)

**Primary goal:** Permission to create/verify a free directory profile.  
**Do not lead with:** advertising, paid acquisition, software, AI automation, or the full ecosystem.

## Where to use it

1. Open Dialpad / calling cockpit in Founder-Led mode  
2. Hit **Call** — when the clinic answers, use the HUD talking points in order  
3. Use **Quick Responses** for objections  
4. Tick the checklist as you capture details  

Source of truth in code:
- `src/lib/calls/founder-led-script.ts` (HUD)
- `src/components/admin/views/call-scripts.tsx` (Script library)

## Call flow (short)

1. Greeting  
2. Free directory + ask for right person  
3. Decision-maker: founder intro → permission ask → **stop**  
4. If yes: verify name, locations, telehealth, services, booking preference, reviewer email  
5. Close: draft for review before publish + follow-up day  

## Traffic answer (honest)

Platform is live. Directory is launching with first clinic partners. Do not exaggerate traffic.

## Capture after every call

Clinic name · person · role · phone · email · permission status · services · telehealth/in-person · locations · website · booking link · decision-maker · follow-up date · concerns · next action
